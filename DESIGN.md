# Design System: Spatial Terminal (Neighborhood DNA)

## Philosophy
- Developer-first, clean dark CLI aesthetic.
- Code snippets (the core "50 lines") take center stage with high-contrast syntax highlighting.
- Zero ornamental clutter: crisp 1px borders, monospaced typography, and high data density.

## Palette
- Canvas / Background: #0B0F19 (deep slate)
- Card Surfaces: #111827 (dark elevated surface)
- Borders & Dividers: 1px solid rgba(255, 255, 255, 0.08)
- Primary Accent: #38BDF8 (Overture cyan)

## Semantic DNA Clusters
- Food, Beverage & Nightlife: #F43F5E (rose)
- Retail, Commerce & Services: #F59E0B (amber)
- Civic, Arts & Culture: #10B981 (emerald)
- Transit & Mobility: #818CF8 (indigo)

## Typography & Components
- Font Family: Inter, -apple-system, sans-serif
- Monospace: JetBrains Mono / Geist Mono for all code, schema definitions, and parameters
- Code Blocks: Native dark container with line numbers, copy button, and semantic tokens
